Files numbered `001` and up are worked verdicts. Each follows the Appendix worksheet of the manuscript: record the range of the claim and the range of the evidence, answer the eight questions, then write the three-sentence verdict (grade, deciding axis, deficiency separating it from the next step up).

## How to read a verdict

The manuscript's own rules apply to everything in this repository:

- A grade is a **diagnosis of a paper**, not a rank of a person. The author of a T6 paper is not a T6 researcher (Chapter 6, Prohibition 1).
- A grade **never travels without its verdict**. Quote the three sentences or quote nothing (Prohibition 4).
- Grades are **not comparable across fields**. Each axis is translated per field; Axis 3 in particular becomes *systematicity of evidence* in qualitative fields (Chapter 2, Prohibition 3).
- Verdicts here are **AI drafts**. The manuscript prescribes a two-layer structure in which the AI drafts and human experts re-examine border cases and upper grades (Chapter 8). Every verdict in this repository is the first layer only.

## Adding a verdict

1. Read backwards: conclusion and abstract, then evidence, then method, then introduction (§4.1). Write the claim sentence and the evidence sentence before reading the introduction.
2. Answer the eight questions with yes / partial / no and one line of reasons each (§4.2).
3. Map answers to a grade (§4.3). T1 is never assigned.
4. Write the three sentences (§4.4). The third sentence, what would move the paper one step up, is the point of the exercise.
5. Name the file `NNN_short_title.md` and add a row to the table above.
